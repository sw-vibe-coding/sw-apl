The keyboard:
  Unshifted letters echo uppercase; turn Caps Lock off.
  Ctrl-] holds the cell before the carriage for an overstrike, so a
  glyph is typed base, Ctrl-], overstrike: Shift-O Ctrl-] Shift-P is
  the logarithm, and A Ctrl-] Shift-F is underscored A. A pair that
  forms no glyph rings the bell and keeps the base.
  Backspace deletes a whole glyph; arrows, Home, End and Delete edit;
  Up and Down recall.
  Shift-L is quad, Shift-K is quote, Shift-apostrophe is ) and F4
  types ) as well.
  Esc quotes the next key. F2 takes keys as the Unicode they already
  are. Paste is literal, one line at a time.
  Ctrl-C and Ctrl-U clear the line. Ctrl-D on an empty line hangs up.

The full key table is docs/terminal.md, and keymap.json holds the map
itself: copy it, edit it to match your keycaps, and pass --keymap.
