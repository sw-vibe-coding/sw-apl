Quad and quote-quad input. Quad on the right prompts with the quad-colon and evaluates the reply as a whole statement in the current environment, so it sees the locals of whatever is running; a reply with no value prompts again and a branch abandons the read. Quote-quad on the right takes the characters as typed with no prompt and no evaluation; on the left it writes them with no line ending, so a prompt and its answer share a line. A read with nothing left to take is INTERRUPT. In batch the line comes from the script, drawn from the same queue the run draws its own from, so the run carries on after whatever the read consumed. The design question was where the prompt lands: a read happens part way through a statement, so buffering output to the end of the statement would print the prompt before the text introducing it. Output and rendering therefore moved below the evaluator into a new apl-console crate together with a Console trait the workspace holds, which is also the seam the web build will replace; apl-quad does the two reads, taking Run rather than depending on the evaluator, the same shape apl-call uses. The print settings moved onto the workspace as Print, which is where APL\360 keeps them and what lets a mid-statement read render what it is about to show. The CLI gained two consoles: batch shares the script queue with its loop, the REPL shares the line editor so a read has the same history. Tests are 255 and 44 transcripts; apl-console got its own test crate because the join after quote-quad output is delicate, and it caught two bugs while being written (a tuple pattern that evaluated the iterator eagerly and swallowed a line, and an output rendering to nothing that closed an open line). A third bug, the batch loop holding a RefCell borrow across its body while a read borrowed the same queue, was found only by running the sample, and now has a CLI test, since no test read from a script before. Boundary recorded as a parity row rather than hidden: a line left open by quote-quad output carries within a statement but not across a statement boundary. All gates clean with only the expected Binary Freshness warning. Commit 88eca71.
