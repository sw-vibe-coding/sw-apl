The I-beam system functions. Monadic I-beam reports the eight values of docs/language.md: 20 time of day, 21 processor time used, 22 space available, 23 terminals connected, 24 time of sign-on, 25 today's date as MMDDYY, 26 the line now executing, 27 every line in the state indicator innermost first, with times in sixtieths of a second. Any other argument is DOMAIN ERROR, as is an argument that is not one whole number, and so is a left argument since there is no dyadic I-beam. What varies between runs is read through a Clock the workspace holds: a clear workspace has one that does not move so a transcript reproduces and a test can say exactly what the clock said, and the terminal installs the real one when a session starts, which is what the new Session::attached does (it also removed the same three lines from both shells). Values 26 and 27 read the activation stack from step 4, which meant run_body had to record its line as it runs rather than only when it fails; that also makes the state indicator accurate for a function inspected while still running. New crate apl-ibeam holds the values and the clock and depends on apl-value alone, with the state indicator reaching it as a parameter, so the workspace can hold its Clock without a dependency cycle; the I-beam is answered in apl-eval rather than apl-prims because what it reports belongs to the workspace, not the value model. samples/58-ibeams.apl (58 rather than the 55 the step named, which the del editor already holds) proves the three clock-dependent values sensible instead of printing them, and ends with the STIR idiom that advances the random link from the clock, showing only the shape and range of what it dealt; verified deterministic by running it twice and diffing. A test caught a regression while being written: intercepting the I-beam before the axis check let a bracketed form ignore its bracket instead of reporting SYNTAX ERROR, which the Phase 2 axis audit had settled. Recorded a parity row on the way past: a monadic-only primitive used dyadically answers NOT IMPLEMENTED where APL\360 should report SYNTAX ERROR. 264 tests, 45 transcripts, all gates clean with only the expected Binary Freshness warning.
