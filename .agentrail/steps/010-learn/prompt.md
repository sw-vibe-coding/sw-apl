Phase 10 step 6 (docs/plan.md). A LEARN workspace in library 1: an introduction to APL for someone who has never used it, in sw-apl. It runs in both modes (one file, NAME.apl.ws), with a version per mode only where a lesson must differ.

Shape: DESCRIBE, then LESSON N for numbered lessons a reader moves through at their own pace (START is lesson 1), and a few drills that make exercises and check the answers read with quad, in the spirit of APLCOURSE's TEACH and EASYDRILL but written fresh for this repository (never converted or quoted from IBM material). The opening lesson uses )DIALECT, )LIBS and )HELP, so a newcomer learns where they are and how to find out more; later lessons cover numbers and vectors, the scalar functions, reduction, shape and indexing, defining a function, and saving a workspace. Lines fit 64 columns. Plan the lessons with the owner before writing them all if the scope is in doubt.

TDD: library tests (lists in both modes, loads, every lesson runs without an error, drills accept a right answer and a wrong one); a sample that walks the first lessons and a drill with scripted answers. Docs: session.md library 1 table, workspaces.md, README, samples/README.
