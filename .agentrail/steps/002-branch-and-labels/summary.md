Branch and labels. A label is a name and a colon at the start of a body line, a local constant holding that line's number, bound with the other locals at call entry and gone on return; a colon anywhere else is not a label. The right arrow takes an expression: the first element of its value selects the next line, an empty vector falls through, and zero or any number that is not one of the function's lines exits returning the result variable's value (running off the last line exits the same way); characters are DOMAIN ERROR, rank above 1 is RANK ERROR. That makes the LABEL-times-iota-COND conditional branch work, so recursion now terminates (FAC 10 = 3628800) with the DEPTH ERROR guard still covering a recursion with no stop.
