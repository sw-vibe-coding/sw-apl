The workspace as a value. Workspace held the symbol table, the state indicator, the settings, a console, a clock, the sign-on time and the pending output together; only some of that can be written to a file and read back, so it is now two halves, with Saved holding the symbol table, the state indicator, the index origin and random link, the print precision and width, and the name the workspace answers to. Saved can be taken out whole, which is what )SAVE will do, and put back, which is what )LOAD will do, and the type stops a console being handed to a serialiser by mistake. The random link goes with it so a loaded workspace carries on its sequence and a transcript that rolls still reproduces. The state indicator is in the saved half rather than the session half, because APL\360 keeps a suspended function with the workspace and )CLEAR takes it with everything else; that is stated in docs/session.md and tested rather than left to be found. )WSID shows the name and sets it, replying WAS the old one as the settings commands do, with an unnamed workspace called CLEAR WS; )CLEAR gives a fresh one and prints CLEAR WS. The commands became one function rather than two, since settings, naming and clearing all change the same value and apl-session is at its module cap, so folding was the choice rather than adding -- and that cap is about to bind, because step 4 of this saga adds seven inquiry commands, so the crate will have to split before then.
