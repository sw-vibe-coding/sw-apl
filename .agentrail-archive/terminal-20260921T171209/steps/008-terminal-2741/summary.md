The browser types on the 2741 keyboard now, and it is the same keyboard aplterm has rather than a second one. apl-board is a new crate: one keystroke in, the line out as JSON, wrapping apl-keyboard compiled to WebAssembly, so the keymap and the overstrike table are not copied into JavaScript. What a keystroke means and what the page draws are both ordinary Rust, tested natively; only the binding is wasm. Verified in a real browser by dispatching keydown events: the minus key types plus, shift-apostrophe w s i d types )WSID, and O Ctrl-] P composes the logarithm glyph. Alt replaces the terminal's Esc for a literal key, and underscored capitals are drawn as they are since the circled form is a terminal-font workaround. Only Ctrl-] and Ctrl-C are taken from the browser. The input element is gone, so a touch screen has nothing to type with until the board is clickable, which is said in the docs rather than left to be found.
