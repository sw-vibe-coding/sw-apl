Read the trouble report forms in the IBM APL/360 User's Manual (Aug 1968) and gave every command the reply the table gives: WS NOT FOUND for a workspace that is not stored ()LOAD, )COPY, )PCOPY, )DROP), OBJECT NOT FOUND for a name the workspace does not hold, IMPROPER LIBRARY REFERENCE for a number that names no library, and INCORRECT COMMAND kept for a command given an argument it does not take. An empty library is not an improper one and still says nothing. The manual also settled two replies that were our own invention: )DROP prints the time and date alone, not DROPPED name or NOT FOUND name, and )SAVE name where a stored workspace of that name is not this one is refused with NOT SAVED, THIS WS IS name rather than overwriting it. )COPY of several names where one is missing copies none, so a copy that half worked cannot pass for one that worked.
