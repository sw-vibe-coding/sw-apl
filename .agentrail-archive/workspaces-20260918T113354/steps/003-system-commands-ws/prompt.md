Phase 4 step 3 (docs/plan.md). The workspace commands: )SAVE )LOAD )DROP )LIB )COPY )PCOPY )CONTINUE. The format is done, so )SAVE is apl-wsfile::write plus a file, and )LOAD is reading the file and running its lines through the session the way batch mode does. Library 0 is work/ and library 1 is ws/lib1/, per docs/session.md; the first )SAVE creates work/ rather than failing. )LIB lists one library at a time, as APL\360 did. Replies: )SAVE prints the timestamp and the id, )LOAD prints SAVED and the timestamp from the file's directive, )DROP removes. )CONTINUE saves as CONTINUE and signs off. )COPY is the one that needs thought rather than translation: the file is re-executable, so copying cannot simply run it -- take the definitions and leave the settings commands alone, or it changes the index origin under code already written. See docs/index-origin-considerations.md. )PCOPY is )COPY that does not overwrite a name already there. apl-session is at its module cap and this step adds seven commands, so split the crate before adding rather than folding again.
