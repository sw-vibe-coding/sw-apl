sw-apl glyph table
==================

Canonical code points accepted by the lexer. Column 1 is the glyph,
column 2 the Unicode code point, column 3 the traditional name,
columns 4 and 5 the monadic and dyadic meanings (blank = none).
This file is UTF-8 and is the source of truth; docs/language.md
refers to it by name.
