# The pages )HELP shows. A page begins with a line
#
#   == NAME MODES GROUP TRY
#
# NAME is a command without its parenthesis, or a topic. MODES is
# the letters of the modes it is for: A (A) '70, B (B) '75, C (C) '80,
# as ABC for all three or A for (A) only; a name may
# have a page for each mode. GROUP is WORKSPACE, LIBRARY, INQUIRY or
# TERMINAL for a command APL\360 had, SW-APL for one sw-apl adds,
# and TOPIC for a topic. TRY, for a command, is a line the tests run
# in each of its modes, which must not answer INCORRECT COMMAND; the
# two that end a session have none.
# Every line fits 64 columns, the width of the (B) '75 screen.
# Comment lines start with #; blank lines inside a page are kept.

== CLEAR ABC WORKSPACE )CLEAR
)CLEAR
REPLACE THE ACTIVE WORKSPACE WITH A CLEAR ONE: NO NAMES, NO
STATE INDICATOR, THE CLEAR WORKSPACE'S SETTINGS, AND NO NAME
OF ITS OWN. REPLIES CLEAR WS.

== WSID ABC WORKSPACE )WSID
)WSID [NAME]
SHOW THE WORKSPACE'S NAME, OR NAME IT. NAMING IT REPLIES WITH
THE NAME IT HAD: WAS CLEAR WS, OR WAS OLDNAME.

== COPY ABC WORKSPACE )COPY 1 LIFE
)COPY [LIB] NAME [OBJECTS]
BRING NAMES OUT OF A SAVED WORKSPACE INTO THIS ONE: ALL OF THEM,
OR THE ONES LISTED. THE SETTINGS STAY AS THEY ARE. REPLIES WITH
THE MOMENT THE WORKSPACE WAS SAVED.

== PCOPY ABC WORKSPACE )PCOPY 1 LIFE
)PCOPY [LIB] NAME [OBJECTS]
AS )COPY, BUT A NAME THIS WORKSPACE ALREADY HOLDS IS KEPT, AND
NAMED IN A NOT COPIED LINE.

== ERASE ABC WORKSPACE )ERASE X
)ERASE NAMES
REMOVE GLOBAL VARIABLES AND FUNCTIONS. A FUNCTION WAITING ON THE
STATE INDICATOR IS NOT ERASED, AND IS NAMED IN THE REPLY.

== GROUP A WORKSPACE )GROUP G X
)GROUP NAME [MEMBERS]
GATHER NAMES UNDER ONE NAME, TO COPY OR ERASE THEM TOGETHER.
ONE NAME ALONE DISPERSES THE GROUP.

== ORIGIN A WORKSPACE )ORIGIN 1
)ORIGIN N
SET THE INDEX ORIGIN, 0 OR 1. REPLIES WAS AND THE OLD ONE.

== DIGITS A WORKSPACE )DIGITS 10
)DIGITS N
SET HOW MANY DIGITS A NUMBER IS SHOWN WITH, 1 TO 16. REPLIES
WAS AND THE OLD NUMBER.

== DEF C WORKSPACE )DEF Z←HELPTRY X
)DEF HEADER
OPEN A NEW FUNCTION, AS )DEF Z←A PLUS B;T. THE PROMPT [N] IS
THE LINE THE NEXT ONE TYPED BECOMES. AN EMPTY LINE, FOR BREAK,
ENDS IT. )HELP EDITOR HAS THE LINE COMMANDS.

== EDIT C WORKSPACE )EDIT NOSUCH
)EDIT NAME
OPEN A FUNCTION THAT EXISTS, AFTER ITS LAST LINE, TO ADD TO IT
OR CHANGE IT. AN EMPTY LINE ENDS IT.

== AUTO C WORKSPACE )AUTO 1
)AUTO [EXPRESSION]
THE EXPRESSION A SAVED WORKSPACE RUNS WHEN IT IS LOADED, OR
NONE. )EXEC RUNS IT NOW.

== EXEC C WORKSPACE )EXEC
)EXEC
RUN THE WORKSPACE'S )AUTO EXPRESSION, IF IT HAS ONE.

== PS C WORKSPACE )PS
)PS
PRINT NUMBERS WITH 6 DIGITS, AS A CLEAR WORKSPACE DOES. ONLY
WHAT IS SHOWN CHANGES; ARITHMETIC KEEPS ITS PRECISION.

== PD C WORKSPACE )PD
)PD
PRINT NUMBERS WITH 15 DIGITS.

== WIDTH A WORKSPACE )WIDTH 120
)WIDTH N
SET HOW WIDE A LINE OF OUTPUT IS, 30 TO 254. REPLIES WAS AND
THE OLD WIDTH.

== SAVE ABC LIBRARY )SAVE HELPTEST
)SAVE [NAME]
KEEP THE WORKSPACE IN LIBRARY 0 UNDER ITS NAME, OR NAME IT AND
KEEP IT. REPLIES WITH THE MOMENT AND THE NAME.

== LOAD ABC LIBRARY )LOAD 1 LIFE
)LOAD [LIB] NAME
REPLACE THE ACTIVE WORKSPACE WITH A SAVED ONE. REPLIES WITH THE
MOMENT IT WAS SAVED. MOST SAVED WORKSPACES HAVE A FUNCTION
CALLED DESCRIBE THAT SAYS WHAT THEY HOLD.

== DROP ABC LIBRARY )DROP HELPTEST
)DROP NAME
FORGET A WORKSPACE SAVED IN LIBRARY 0.

== LIB ABC LIBRARY )LIB 1
)LIB [N]
LIST THE WORKSPACES IN LIBRARY 0, OR IN LIBRARY N, THAT RUN IN
THIS MODE. LIBRARY 0 IS YOURS; LIBRARY 1 IS WHAT SW-APL SHIPS.

== FNS ABC INQUIRY )FNS
)FNS [LETTER]
LIST THE DEFINED FUNCTIONS, ALPHABETICALLY, FROM A LETTER.

== VARS ABC INQUIRY )VARS
)VARS [LETTER]
LIST THE GLOBAL VARIABLES, ALPHABETICALLY, FROM A LETTER.

== GRPS A INQUIRY )GRPS
)GRPS [LETTER]

== GRP A INQUIRY )GRP G

== SI ABC INQUIRY )SI
)SI
THE STATE INDICATOR: EACH FUNCTION STOPPED OR WAITING, WITH ITS
LINE. A STAR MARKS THE ONE AN ERROR STOPPED. A BARE RIGHT ARROW
CLEARS THE TOP ENTRY; AN ARROW AND A LINE NUMBER RESUMES.

== SIV ABC INQUIRY )SIV
)SIV
AS )SI, WITH THE NAMES EACH CALL MADE LOCAL.

== SYMBOLS ABC INQUIRY )SYMBOLS
)SYMBOLS
HOW MANY NAMES THE WORKSPACE HOLDS, AND HOW MANY WOULD FIT.

== TRON C TERMINAL )TRON
)TRON
TRACE: NAME EACH LINE OF A FUNCTION, AS F[2], BEFORE IT RUNS.

== TROFF C TERMINAL )TROFF
)TROFF

== OFF ABC TERMINAL
)OFF

== CONTINUE ABC TERMINAL
)CONTINUE

== DIALECT ABC SW-APL )DIALECT
)DIALECT
WHICH MODE THIS SESSION IS IN: (A) '70 OR (B) '75. IT ONLY
ASKS; THE MODE IS CHOSEN WHEN THE SESSION STARTS.

== LIBS ABC SW-APL )LIBS
)LIBS
THE LIBRARIES THIS SESSION REACHES, BY NUMBER: 0 USER, WHICH
IS YOURS; 1 CORE, WHAT SW-APL SHIPS; AND ANY CONFIGURED BEYOND
THEM, SUCH AS 2 EXTENDED. )LIB N LISTS ONE, )LOAD N NAME LOADS

== HELP ABC SW-APL )HELP
)HELP [NAME]

== MODES ABC TOPIC
MODES
SW-APL HAS THREE MODES, CHOSEN WHEN A SESSION STARTS.

(A) '70, APL\360-INSPIRED: I-BEAMS FOR SYSTEM VALUES, AND
)ORIGIN, )DIGITS AND )WIDTH FOR SETTINGS.

(B) '75, IBM 5100-INSPIRED: THE SAME CORE, WITH EXECUTE, FORMAT
AND THE QUAD SYSTEM VARIABLES AND FUNCTIONS, SUCH AS QUAD IO AND
QUAD FX, AND NO I-BEAMS OR SETTINGS COMMANDS.

(C) '80, TRS-80-INSPIRED: THE CORE WITH SCAN, LESS WHAT APL80
LEFT OUT: DOMINO, LAMINATION, THE DIAGONAL TRANSPOSE, THE
HYPERBOLIC FUNCTIONS, AND TWO SPECIFICATIONS IN A STATEMENT.
FACTORIAL TAKES WHOLE NUMBERS, ENCODE AND DECODE VECTORS. AT
MOST 32 FUNCTIONS OF 255 LINES. SIX DIGITS IN A LINE OF 64.
FUNCTIONS ARE DEFINED WITH )DEF, NOT THE DEL, AND A WORKSPACE
SAVED IN (C) RUNS IN (C) ALONE.

EACH MODE LISTS AND LOADS ONLY THE WORKSPACES THAT RUN IN IT.
DOCS/MODES.MD COMPARES THEM, AREA BY AREA.

(B) HAS NO CLOCK, AS THE 5110 HAD NONE: QUAD TS IS IN 1900. A
SESSION STARTED WITH --CLOCK HARDWARE READS THE COMPUTER'S.

== EDITOR A TOPIC
EDITOR
∇HEADER OPENS A NEW FUNCTION, AS ∇R←A F B;L. ∇NAME REOPENS
ONE AFTER ITS LAST LINE. THE PROMPT [N] IS THE LINE THE NEXT
LINE TYPED BECOMES. ∇ CLOSES AND RENUMBERS FROM 1; ⍫ CLOSES
IT LOCKED. A COMMAND MAY FOLLOW THE NAME: ∇F[⎕]∇ SHOWS F.
[N]        GO TO LINE N. [N] TEXT WRITES LINE N.
[1.5]      A LINE BETWEEN 1 AND 2.
[∆N]       DELETE LINE N.
[0]        THE HEADER: [0] R←G X CHANGES IT, NAME AND ALL.
[⎕]        SHOW THE WHOLE FUNCTION.
[⎕N]       SHOW FROM LINE N ON, THEN OFFER THE LAST SHOWN.
[N⎕]       SHOW LINE N ALONE, THEN OFFER IT FOR RETYPING.
[N⎕M]      CHANGE PART OF LINE N. IT IS SHOWN; UNDER IT, FROM
           COLUMN M, TYPE / TO DELETE THE CHARACTER ABOVE, A
           DIGIT K TO OPEN K BLANKS BEFORE IT, OR A LETTER TO
           OPEN 5 PER LETTER (A 5, B 10). IT IS SHOWN AGAIN:
           TYPE INTO THE BLANKS, A BLANK KEEPING WHAT IS THERE.
           A CHANGED [N] PUTS THE LINE AT THE NEW NUMBER.

== EDITOR C TOPIC
EDITOR
)DEF HEADER OPENS A NEW FUNCTION AND )EDIT NAME AN OLD ONE,
EACH AT ITS FIRST UNUSED LINE. TYPE A LINE AND IT IS ADDED.
AN EMPTY LINE, FOR BREAK, ENDS THE DEFINITION. THERE IS NO DEL.
)?         SHOW THE FUNCTION, LINE 0 BEING THE HEADER.
)P N       SHOW 14 LINES FROM LINE N.
)N         DELETE LINE N AND ASK FOR ITS REPLACEMENT. END THE
           DEFINITION OR TYPE )? INSTEAD, AND IT STAYS DELETED.
)0         REPLACE THE HEADER. THE NAME STAYS THE SAME.
)E N       OFFER LINE N TO TYPE OVER; RETURN ENTERS IT.
EVERY CHANGE RENUMBERS THE LINES AT ONCE.

== EDITOR B TOPIC
EDITOR
∇HEADER OPENS A NEW FUNCTION, AS ∇R←A F B;L. ∇NAME REOPENS
ONE AFTER ITS LAST LINE. THE PROMPT [N] IS THE LINE THE NEXT
LINE TYPED BECOMES. ∇ CLOSES AND RENUMBERS FROM 1; ⍫ CLOSES
IT LOCKED. A COMMAND MAY FOLLOW THE NAME: ∇F[⎕]∇ SHOWS F.
[N]        GO TO LINE N. [N] TEXT WRITES LINE N.
[1.5]      A LINE BETWEEN 1 AND 2.
[∆N]       DELETE LINE N.
[0]        THE HEADER: [0] R←G X CHANGES IT, NAME AND ALL.
[⎕]        SHOW THE WHOLE FUNCTION.
[⎕N]       SHOW FROM LINE N ON, THEN OFFER THE LAST SHOWN.
[N⎕]       PUT LINE N IN THE INPUT LINE, TO TYPE OVER IN
           PLACE; RETURN ENTERS IT. A CHANGED [N] PUTS IT AT
           THE NEW NUMBER. [N⎕M] DOES THE SAME.

== EXTENSIONS ABC TOPIC
EXTENSIONS
COMMANDS SW-APL ADDS, WHICH NO HISTORICAL SYSTEM HAD:
)DIALECT      WHICH MODE THIS SESSION IS IN
)LIBS         THE LIBRARIES THIS SESSION REACHES
)HELP         THIS HELP
THEY ARE SYSTEM COMMANDS AND NEVER QUAD NAMES, SO NO PROGRAM
CAN DEPEND ON THEM.

== RESTRICTIONS ABC TOPIC
RESTRICTIONS
WHAT SW-APL DOES NOT DO, AND WHY:
- THE COMMANDS OF A SHARED MACHINE: )MSG, )OPR, )PORTS,
  )NUMBER AND THE REST. SW-APL HAS ONE USER.
- A SAVED WORKSPACE DOES NOT KEEP A SUSPENDED FUNCTION: IT IS
  TEXT, AND TEXT CANNOT RESUME PART WAY THROUGH A CALL.
- A LOCKED FUNCTION IS OBSCURED IN A SAVED FILE, NOT
  ENCRYPTED.
DOCS/PARITY.MD AND DOCS/EMULATION-POLICY.MD HAVE THE REST.
